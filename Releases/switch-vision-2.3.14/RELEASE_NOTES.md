# Switch Vision Core v2.3.14 — Test Mode control spacing

Switch Vision Core v2.3.14 simplifies the Calibration LED Test Mode control placement.

- Restores the normal Calibrate button to its original stock top-right position.
- Places TEST MODE directly beneath Calibrate with a 10 px gap.
- Keeps TEST MODE the same width, height and alignment as Calibrate.
- Corrects stock profiles moved by v2.3.13 while preserving genuinely customised Calibrate positions.
- Keeps all v2.3.12 Test Mode persistence behaviour unchanged.

After updating Core through Switch Vision Installer, restart Home Assistant Core when prompted.
