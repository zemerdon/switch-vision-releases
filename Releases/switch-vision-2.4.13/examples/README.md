# Switch Vision examples

Core-owned example filenames follow the Core release version. Discovery examples remain unversioned because Switch Vision Discovery is independently versioned.

| File | Purpose |
|---|---|
| `discovery-addon-options.yaml` | Complete Discovery options example for a stack and additional switches. |
| `discovery-targets.example.csv` | Optional CSV target mapping example. |
| `discovery-profiles.yaml` | Example profile mappings used by Discovery. |
| `discovery-generated-dashboard-card.yaml` | Review-only card YAML generated by Discovery. |
| `live-dashboard-v2.4.13.yaml` | Production-style manual dashboard example. |
| `calibration-dashboard-v2.4.13.yaml` | Manual dashboard with Calibration enabled. |
| `test-env-*.yaml` | Test-environment variants with and without Layout Card. |

Current examples use:

```yaml
- type: custom:switch-vision-3650
```

For a manual/custom YAML dashboard, register:

```text
/local/switch-vision/js/switch-vision.js?v=2.4.13
```

Generated layouts using Layout Card also require:

```text
/hacsfiles/lovelace-layout-card/layout-card.js
```

The native Switch Vision sidebar panel loads its resources automatically and does not require either manual resource.

See `../docs/FIELD_REFERENCE.md` for field descriptions and `../docs/UPGRADING.md` for version-update guidance.
