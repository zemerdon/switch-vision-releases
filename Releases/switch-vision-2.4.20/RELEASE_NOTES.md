# Switch Vision Core v2.4.20

Core 2.4.20 fixes the HAOS dashboard configuration failure exposed after the small UniFi factory profiles were added.

The UCG Ultra and USW Ultra factory calibrations now satisfy the Core calibration contract with explicit empty `status_leds` objects, and the authenticated calibration backend accepts schema version 2 profiles generated by the current calibration workflow. No status LEDs are invented for either device.

Community-dashboard runtime-version discovery is also bounded to one second. If Home Assistant is under startup WebSocket backpressure, Switch Vision falls back to the versioned frontend resource instead of allowing the Lovelace strategy bootstrap to wait indefinitely and collapse into Home Assistant's generic `Configuration error` state.

The authoritative 2.4.19 `unifi-5rj45.png` and `unifi-8rj45.png` payloads, their exact SHA-256/size regressions, port geometry, UniFi API mappings, PoE semantics, telemetry, privacy metadata and Experimental support status are unchanged.
