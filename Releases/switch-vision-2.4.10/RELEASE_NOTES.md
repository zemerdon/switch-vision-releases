# Switch Vision Core v2.4.10

Adds exact UniFi API hardware contracts from community-provided real-hardware validation.

`USW Pro Max 24` receives exact 24+2 dashboard geometry with its verified split of 16 × 1G copper, 8 × 2.5G-capable copper and 2 × 10G SFP+. `US 16 PoE 150W`, `USW Ultra`, and the integrated switch in `UCG Ultra` are exact hardware/API models while dedicated small/legacy faceplates remain intentionally pending. Discovery can render those devices through its safe generic-card fallback while preserving real observed port counts.

Public release notes intentionally omit contributor identities, submission identifiers, contribution package names, and submission filenames. Per-port traffic remains unavailable through this UniFi API path and is not fabricated by Switch Vision.
