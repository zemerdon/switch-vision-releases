Switch Vision bundled faceplates

- 48rj45-4sfp.png — default 48-port, four-uplink faceplate; used by Catalyst 3650 and Juniper EX3300 profiles
- 48rj45-2sfp.png — 48-port, two-uplink faceplate; used by WS-C2960S-48FPD-L and WS-C2960X-48FPD-L
- 24rj45-4sfp.png — 24-port, four-uplink faceplate; used by WS-C2960X-24PS-L
- 24rj45-2sfp.png — bundled 24-port, two-uplink faceplate for future compatible profiles

All faceplates use the standard Switch Vision 2048 x 448 canvas.
- submarine-48rj45-4sfp.png — alternative submarine-themed 48-port, four-uplink faceplate; bundled with its own faceplate-selection calibration defaults
- c3560cg-8pc-s.png — dedicated slim 8-port / dual-purpose uplink faceplate; default for WS-C3560CG-8PC-S

- unifi-24p-rj45-2sfp.png — default UniFi / Ubiquiti faceplate; current UniFi model mappings recommend this artwork
Faceplate artwork may use native source dimensions; Switch Vision scales it to the calibration canvas at runtime.
- unifi-24-rj45-2sfp-dark.png — manual-only dark UniFi alternative; uses the exact unifi-24p-rj45-2sfp.png calibration geometry and is not mapped to any model
